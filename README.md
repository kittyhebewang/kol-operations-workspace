# KOL Operations Workspace

一个面向 KOL / Influencer Marketing 团队的运营管理工作台 Demo。

用于展示从达人管理、报价审批、合作项目、合同管理、视频交付到付款流程的完整业务闭环。

🌐 Live Demo  
https://kittyhebewang.github.io/kol-operations-workspace/

---

## ✨ 项目介绍

KOL Operations Workspace 是一个单页面 Web 应用原型，模拟真实 KOL 运营团队日常使用的内部管理系统。

目标是解决 Influencer Marketing 团队在合作过程中：

- 达人信息分散
- 报价审批流程不透明
- 合同状态难追踪
- 视频交付缺少统一管理
- 付款资料收集混乱

等运营问题。

---

## 🚀 功能模块

### 📊 Dashboard 总览

- 合作项目概览
- 待处理事项提醒
- 合作流程漏斗展示
- 数据统计展示


### 👤 达人库（Creator Database）

支持管理：

- 达人昵称
- 联系邮箱
- 国家 / 地区
- 语言
- 平台信息
- 合作状态
- 跟进负责人


### 💰 报价管理（Quote Management）

支持：

- 创建达人报价
- 记录 Campaign 信息
- 平台发布数量
- 广告授权周期
- 主管审核流程
- 驳回修改记录


### 📄 合同管理（Contract Management）

支持：

- 合同状态追踪
- 合同上传
- 合同确认流程
- 合作单关联


### 🎬 视频交付（Content Delivery）

支持：

- 视频链接提交
- 发布日期记录
- Spark Ads / Meta 授权码管理
- 授权有效期计算
- 审核状态管理


### 💳 付款管理（Payment Management）

支持：

- 自动生成付款任务
- Invoice 信息管理
- 付款状态追踪
- 资料补充提醒


### 🔐 团队权限 Demo

包含角色：

| 角色 | 权限 |
| --- | --- |
| 运营 | 达人录入、报价提交、合作跟进 |
| 主管 | 审核报价、确认合同、确认交付 |
| 财务 | 付款处理、资料审核 |
| 管理员 | 全量权限 |
